readable & writable

可读，也可写

默认是「大纲 | 源码 | 预览」三栏：中间专心改 Markdown，右侧即时看到排版结果，左侧大纲一键跳转。 也可以切到所见即所得，或打开专注 / 打字机模式，把注意力留在当前这一段。

  • 源码三栏 大纲导航、源码编辑、增强预览并排；同步滚动，改哪看哪。
  • 所见即所得 一键切换可视化编辑；保存与切回源码时，仍以 Markdown 原文为准。
  • 专注 / 打字机 专注模式收起侧栏与预览；打字机模式让当前行尽量落在视口中央。
  • 智能粘贴 从浏览器或 Word 复制的 HTML，会尽量转成干净的 Markdown 再贴入。
  • 多页签 像记事本一样同时开多个文件；双击页签空白处即可新建；钉子可把常用页签置顶到左侧。
  • 字数统计 状态栏显示行、列，以及全文或选区的字数与词数。

simple, yet powerful

简单，却够用

常用 Markdown 语法开箱即用；增强预览在离线环境下也能渲染代码高亮、公式与图表。

  • 标题与列表 ATX 标题、有序 / 无序 / 任务列表、引用、表格、脚注与 [TOC]。
  • 代码高亮 围栏代码块按语言着色，阅读技术笔记时更轻松。
  • 数学公式 支持行内与块级 KaTeX 公式，适合课堂笔记与技术推导。
  • Mermaid 图表 流程图、时序图等可用文本描述，预览中直接成图。
  • YAML Front Matter 文首元数据不会干扰正文预览，与静态站点工作流兼容。
  • 图片落盘 粘贴截图或拖入图片，自动保存到笔记旁 assets/，并插入相对路径。

you focus on the content

文件与结构，交给侧栏

把笔记放进同一个文件夹，用文件树浏览，用库内搜索找回半个月前那句原话。

笔记库侧栏

根目录即 DeskTidy 配置的笔记文件夹。双击打开，已打开则切到对应页签。

  • 新建 Markdown
  • 刷新 / 在资源管理器中打开
  • 专注模式下自动隐藏

库内搜索

按文件名与正文内容检索；命中后可跳到首处匹配行。

  • 快捷键 Ctrl+Shift+F
  • 大纲面板一键跳标题
  • 会话恢复：下次打开还在

share what you wrote

导出与分享

写完不必困在编辑器里：按用途导出即可继续流转。

  • 导出 HTML 生成可离线打开的单页 HTML，便于归档或内部分享。
  • 导出 PDF 基于增强预览引擎打印为 PDF（需 WebEngine 环境）。
  • 导出 Word 若本机已安装 Pandoc，可一键转为 .docx；未安装时会提示安装方式。

ships with DeskTidy

独立软件，和桌面整理在一起

DeskNote 是独立进程与窗口，任务栏显示为 DeskNote； 安装 DeskTidy 时一并带上，共用设置与默认笔记目录。 围栏里「用记事本打开」也可直接唤起它。

在 DeskNote 里按 F1 打开本页（DeskNote 介绍 + 使用手册）。 DeskTidy 分区/分页等请到 DeskTidy 主窗口「帮助」打开另一份网页。
