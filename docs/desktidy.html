下载 DeskTidy

Windows 安装包，安装后即可使用桌面分区、分页、截图录屏、云端账号管理与 DeskNote。

DeskTidy Setup

安装包体积约 214 MB（含 DeskNote 与录屏组件）。分区只钉选显示，不挪动你的文件。

v4.0.25 Windows 10 / 11 x64
下载安装包（GitHub） 先看使用手册

点击后从 GitHub Releases 下载 DeskTidy_Setup_4.0.25.exe，双击即可安装。源码与发行说明见 github.com/Bowen-Yu0926/DeskTidy。

安装提示

  • 默认安装到当前用户目录，一般无需管理员权限
  • 可选创建桌面快捷方式与开机启动
  • 卸载可在开始菜单或「应用和功能」中进行

/* fences, not folders */

分区：分类显示，不挪文件

分区是桌面上的分类容器。拖入图标即钉选显示；一键整理可按规则自动归类。 删除分区不会删除文件——只是撤掉「钉选」。

虚拟钉选

文件仍在系统桌面文件夹；分区只负责怎么显示、怎么找。

一键整理

按软件 / 文档等规则批量钉选；支持白名单跳过重要路径。

拖放与缩放

拖标题移动、拖边缘改大小、折叠收起；拖出到空白即取消钉选。

文件夹门户

分区可镜像真实文件夹：拖入 / 拖出按系统规则真正复制或移动。

系统菜单

图标右键仍是熟悉的资源管理器菜单，并附加移出分区、记事本打开等。

Peek 与热键

快速显隐分区、置顶查看；全局热键可在设置里改。

/* many desktops, one screen */

分页：多套布局，随时切换

「工作」「娱乐」可以是两套完全不同的分区布局。切换分页只改变 DeskTidy 显示哪一套， 不等于 Windows 虚拟桌面——两边可以一起用。

怎么切换

  • 右侧浮标栏单击页名
  • 快捷键上一页 / 下一页
  • 主窗口「桌面分区」统一管理

布局快照

  • 保存整套分区位置与配置
  • 预览后再还原
  • 换机或大调整前先拍一张

/* capture & find */

截图、录屏与搜索

整理之外，把常用桌面工具收在同一套热键里。

区域截图

框选桌面区域，复制 / 保存 / 贴图；可点选窗口区域。

桌面录屏

一键开始与结束录制（依赖本机 FFmpeg）。

文件搜索

快速找到本地文件；可配合扩展选项调整范围。

公共区域

从分区拖出的图标可按设置在多分页间共享显示。

双击隐藏图标

建议开启：减少系统图标与分区、浮标叠在一起。

托盘常驻

关主窗口仍可整理、截图、开帮助；不打扰工作流。

/* accounts, synced */

账号管理：桌面浮标，云端同步

在侧栏「账号管理」启用后，桌面会出现独立的「账」圆标（不在分页栏上）。 单击在浮标旁打开清单：名称、账号、密码、网址可增删改；双击字段即可复制。 用手机号或邮箱注册登录后，换设备也能拉回同一份清单。

桌面「账」浮标

可拖动定位；单击打开 / 收起面板。关闭面板后切页不会再把它唤起。

登录与同步

无验证码；登录态保存在本机配置目录。后台默认定时静默刷新。

复制与维护

密码默认掩码；可搜索、导入导出 JSON。条目也可写一条 DeskNote 备注。

按需开启

默认关闭。服务器不可达时会提示并自动关掉，避免卡住 DeskTidy。

/* extras on the side */

扩展：需要时再打开

会议纪要、计算器、桌面待办、云端账号管理、桌面宠物、壁纸与分页文件夹——按需启用。

会议纪要

在指定文件夹生成 Word 纪要，方便会后整理。

计算器 / 待办

快捷呼出计算器；桌面待办钉在眼前。

账号管理

详见上方 账号管理：云端清单 + 桌面「账」浮标。

桌面宠物

可互动的小伴侣。详见下方 桌面宠物 专节。

/* a tiny desk buddy */

桌面宠物：陪着你收拾桌面

在扩展里打开后，宠物会停在桌面上：可以摸摸、等待、睡觉、甩出去跌落； 也能把图标拖到它身上，揉成纸团丢进回收站。形象与大小可在设置里改。

摸摸 / 等待 / 睡觉

单击摸摸会开心回应；「⋯」菜单可点等待、睡觉。未勾选的动作不会出现在菜单里，「隐藏」始终可用。

拖动与跌落

按住拖动可换位置；甩出去会抛物线落地。位置与大小会记在你的配置里。

拖文件给它

把桌面或分区里的图标拖到宠物身上，会揉成纸团进系统回收站（可还原）。别拖到头上的分页浮标。

大小与浮标

设置里可调约 50%～160% 显示比例。可选把右侧浮标栏放到宠物头上，分页、录屏等更顺手。

/* ships with DeskNote */

DeskNote：一起装上的 Markdown 笔记

独立窗口与进程，支持源码三栏 / 所见即所得、公式与 Mermaid、文件树与库内搜索、 本地图片落盘，以及导出 HTML / PDF / Word。与 DeskTidy 共享笔记目录与主题。
