# deskNote Markdown 增强 · 二期设计

**日期：** 2026-09-10  
**状态：** 实现中（用户「继续」）  
**承接：** 一期 Web 预览 + 导出  

## 范围

1. **专注模式**：隐藏菜单外干扰，编辑区居中加宽（源码模式）。  
2. **打字机模式**：当前行尽量保持在视口垂直居中。  
3. **智能粘贴**：剪贴板含 HTML 时粘贴为 Markdown（Ctrl+V / 菜单粘贴）；纯文本不变。  
4. **所见即所得**：查看菜单切换「源码三栏 / 所见即所得」；WYSIWYG 用 Toast UI Editor（离线 vendor），与 `QPlainTextEdit` 双向同步 Markdown。  

无 WebEngine 时：专注/打字机/智能粘贴仍可用；WYSIWYG 入口禁用并提示。

## 非目标（三期）

文件树、库内搜索、图床、Pandoc。
