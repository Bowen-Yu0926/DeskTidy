# deskNote Markdown 增强 · 三期设计

**日期：** 2026-09-10  
**状态：** 实现中（用户「继续」）  
**承接：** 二期 WYSIWYG / 专注 / 打字机 / 智能粘贴  

## 范围

1. **笔记库侧栏**：根目录 = 配置的笔记文件夹；`QFileSystemModel` + `QTreeView`。  
2. **打开文件**：双击打开/切到已有页签；可新建 `.md`、刷新、资源管理器打开。  
3. **库内搜索**：侧栏搜索框（Ctrl+Shift+F）；文件名 + 内容（限文本、大小上限）。  
4. **查看 · 文件树** 开关（默认开）；专注模式隐藏。  

## 非目标（四期）

图床、Pandoc/Word、多根工作区。
