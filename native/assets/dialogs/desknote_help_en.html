Overview

DeskNote is an optional standalone notepad installed with DeskTidy: multi-tab editing of common text/code, with a note-library sidebar, preview/edit toggle, WYSIWYG, focus/typewriter modes and smart paste for .md.

ActionNotes
How to openDeskNote shortcut on desktop / Start menu; or enable the shortcut in DeskTidy → Extensions.
Default save locationThe 「笔记」(Notes) folder under the install directory (changeable in DeskTidy → Extensions).
Window closeClosing the window keeps tab contents for next launch; closing a tab cleans up its draft/note file per rules.

This help covers DeskNote only. DeskTidy desktop-fence features are in the DeskTidy main-window Help.

Tabs & Files

One window can hold several tabs, like Notepad++.

ActionNotes
File · New / Ctrl+NCreate and open a new Markdown file in the notes folder (e.g. 未命名.md).
Double-click empty tab barSame — create a new file in the notes folder.
File · Open / Ctrl+OOpen text, Markdown, and common code/config files.
Drop filesDrag text / Markdown / code files into the window to open them as tabs.
File · Save / Ctrl+SSave the current tab.
File · Save AsSave to a new path or extension (e.g. convert to .md).
Open Notes FolderOpen the default notes directory in Explorer.
Close tab / Ctrl+WClose the current tab; asks whether to save when there are unsaved changes. Middle-click a tab also closes it.
Tab pin / right-click pinClick the pin on the left of a tab to fix it to the far left; click again to unpin. Pin state persists across sessions.
Tab / library file right-clickOpen, rename, pin/unpin, close, delete (same menu in both places). Close only closes the tab; delete removes the file from disk.
Close windowEnds this window; opened content is kept for the next launch as much as possible.

Note Library Sidebar

A left file tree browsing the default notes folder (path changeable in DeskTidy → Extensions).

ActionNotes
View · File tree / Ctrl+Shift+EShow or hide the sidebar.
Double-click a fileOpen it; if already open, switch to that tab.
+ / right-click blank · New MarkdownSame as File · New: create a .md in the notes root and open it.
File right-clickSame as tab right-click: open, rename, pin, close (if open), delete.
Right-click · Rename / F2Renames only the filename stem; the extension (.md etc.) is kept; open tabs follow the new path.
Right-click · Delete / DeleteDeletes the file; if open, closes the corresponding tab.
Search box / Ctrl+Shift+FSearches the note library by filename and content (large files are skipped).
Blank-area right-clickNew Markdown, refresh, or open the notes folder in Explorer.

In focus mode the sidebar auto-hides; exiting focus restores it per your File-tree toggle.

Markdown Preview & Editing

Opening .md / .markdown defaults to full-width preview; click the right-side Edit bar to edit, then Preview to return.

ActionNotes
Open .mdDefaults to full-width preview (code highlight, formulas, Mermaid, footnotes, [TOC]).
View · Preview / Ctrl+Shift+VSwitch to preview.
View · Edit / Ctrl+ESwitch to edit (source or WYSIWYG).
Edit · OutlineOptional left outline in source-edit mode (Ctrl+Shift+O).
File · Export HTML / PDFExport current Markdown; PDF needs the enhanced preview engine.
File · Export WordConvert to .docx via local Pandoc; install hint shown when missing.
Paste / drop imageIn edit mode, paste screenshots or drop images — saved beside the note under assets/ with a relative path inserted.

Plain .txt etc. files have only an edit area, no Markdown preview.

Editing Modes

Enter the Edit view first, then choose source or WYSIWYG from the View menu (requires a saved .md).

ActionNotes
View · Source editingOptional left outline + source editor.
View · WYSIWYGToast UI visual editing; Markdown is synced back before switching/saving. Requires WebEngine.
View · Focus mode / F11Hides sidebar and status bar, full-width source editing; exit restores layout.
View · Typewriter modeKeeps the caret line vertically centered for long-form writing.

Focus mode forces source editing. Typewriter mode applies only to the source editor.

Headings & Outline

The outline levels ATX headings. Canonical form is「hash + space + title」.

LevelMarkup
Level 1# Title
Level 2## Title
Level 3### Title (up to six ######)
Missing space###Title is still recognized when possible; prefer the space.
Click outline itemMoves the caret to that source line, centered when possible.

Preview supports lists, task lists, quotes, code highlight, tables, links, images, formulas, Mermaid, [TOC] and footnotes; leading YAML front matter is not shown as body.

DeskTidy Integration

DeskNote is a standalone process installed with DeskTidy, sharing settings and the notes folder.

ActionNotes
InstallDeskNote installs together with DeskTidy; no separate component checkbox.
EnableToggle the shortcut in DeskTidy → Extensions → DeskNote (does not uninstall the program).
Explorer · Open withThe Open-with list for text / Markdown / code files offers DeskNote (no longer DeskTidy).
Fence「Open in Notepad」Open text files with DeskNote.
Single instanceLaunching DeskNote again activates the existing window instead of opening a new one.
ThemeFollows the current DeskTidy theme setting.
Account vaultWhen DeskTidy account management is enabled, DeskNote shows an Accounts web view: search, double-click copy, reveal, add/edit. Saves locally and uploads when signed in.
