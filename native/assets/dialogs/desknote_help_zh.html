DeskNote 总览

DeskNote 是与 DeskTidy 同包可选安装的独立记事本：多页签编辑常见文本/代码， 并对 .md 提供笔记库侧栏、所见即所得、专注/打字机模式与智能粘贴。

操作说明
怎么打开桌面 / 开始菜单的 DeskNote 快捷方式；或在 DeskTidy 扩展里启用快捷方式。
默认保存位置安装目录下的「笔记」文件夹（可在 DeskTidy → 扩展功能里改）。
窗口关闭关闭窗口会保留页签内容，下次打开还会在；关掉某个页签会按规则清理对应草稿/笔记文件。

本帮助只讲 DeskNote。DeskTidy 桌面分区等功能请在 DeskTidy 主窗口「帮助」里查看。

页签与文件

一个窗口可开多个页签，类似 Notepad++。

操作说明
文件 · 新建 / Ctrl+N在笔记库文件夹新建 Markdown（如未命名.md）并打开。
页签栏空白处 · 双击同上，在笔记库中新建文件。
文件 · 打开 / Ctrl+O打开文本、Markdown、常见代码与配置文件。
拖入文件把文本 / Markdown / 代码文件拖进窗口即可打开为页签。
文件 · 保存 / Ctrl+S保存当前页签。
文件 · 另存为换路径或换后缀保存（如改成 .md）。
打开笔记文件夹在资源管理器中打开默认笔记目录。
关闭页签 / Ctrl+W关闭当前页签；有未保存修改时会询问是否保存。点页签右侧 × 或中键点击页签也可关闭。
页签 · 双击 / 右键重命名双击页签标题区域弹出重命名；只改文件名主体，扩展名保持不变。
页签 · 图钉 / 右键置顶点击页签左侧图钉可将该页签固定到最左侧；再次点击取消。置顶状态会随会话保留。
页签 / 笔记库文件 · 右键打开、重命名、置顶/取消置顶、关闭、删除（两侧菜单一致）。关闭仅关页签；删除会移出磁盘文件。
关闭窗口结束本窗口；已打开内容会尽量保留到下次启动。

笔记库侧栏

左侧文件树浏览默认笔记文件夹（可在 DeskTidy → 扩展功能里改路径）。

操作说明
查看 · 文件树 / Ctrl+Shift+E显示或隐藏侧栏。
双击文件打开；若已在页签中则切换过去。
+ / 空白处右键 · 新建 Markdown与「文件 · 新建」相同：在笔记根目录新建 .md 并打开。
文件右键与页签右键相同：打开、重命名、置顶、关闭（已打开时）、删除。
右键 · 重命名 / F2只改文件名主体，扩展名（如 .md）保持不变；已打开的页签会跟上新路径。
右键 · 删除 / Delete删除文件；若已打开则同时关闭对应页签。
搜索框 / Ctrl+Shift+F按文件名与正文内容搜索笔记库（大文件会跳过）。
搜索结果右键菜单与文件树一致（打开 / 重命名 / 置顶 / 关闭 / 删除）。
标题栏 + / 刷新「+」新建 Markdown；「刷新」重载文件夹。空白处右键可打开笔记库目录。
空白处右键新建 Markdown、刷新，或在资源管理器中打开笔记文件夹。
文件右键重命名、置顶、打开文件所在目录、删除；关闭页签请点页签上的 ×。

专注模式下侧栏会自动隐藏，退出专注后按你的「文件树」开关恢复。

编辑与查找

操作说明
撤销 / 剪切 / 复制 / 粘贴 / 全选编辑菜单或常规系统快捷键。
粘贴（Markdown）剪贴板含 HTML（如浏览器/Word）时，自动转成 Markdown 再粘贴；纯文本则原样粘贴。
格式 · 自动换行按窗口宽度折行；可关闭以便看长行。
查找 / Ctrl+F在当前页签内查找。
替换 / Ctrl+H查找并替换；可作用于当前页或全部页签（见查找对话框选项）。
F3 / Shift+F3查找下一个 / 上一个。
状态栏显示路径、是否已修改，以及当前行、列与字数（有选区时统计选区）。

Markdown 编辑与导出

打开 .md / .markdown 时直接进入编辑。可用「文件 · Markdown 预览窗口」单独打开预览。

操作说明
打开 .md进入源码或所见即所得编辑。
查看 · 编辑 / Ctrl+E切到编辑（源码或所见即所得）。
文件 · 导出 HTML / PDF导出当前 Markdown；PDF 需增强预览引擎。
文件 · 导出 Word调用本机 Pandoc 转为 .docx；未安装时会提示安装方式。
粘贴 / 拖入图片在编辑模式下粘贴截图或拖入图片，保存到笔记旁 assets/ 并插入相对路径。

普通 .txt 等文件只有编辑区，不会进入 Markdown 预览。

编辑模式

先进入「编辑」视图，再在「查看」菜单选择源码或所见即所得（需已保存为 .md）。

操作说明
查看 · 源码编辑源码编辑区。
查看 · 所见即所得Toast UI 可视化编辑；切回源码/预览或保存前会同步 Markdown 原文。需 WebEngine。
查看 · 专注模式 / F11隐藏侧栏与状态栏，全宽源码编辑；退出后恢复编辑布局。
查看 · 打字机模式光标所在行尽量垂直居中，便于长文连续输入。

专注模式强制进入源码编辑。打字机模式仅作用于源码编辑区。

标题与大纲

大纲按 ATX 标题分级。规范写法是「井号 + 空格 + 标题」。

操作说明
一级# 标题
二级## 标题
三级### 标题（最多六级 ######）
手敲漏空格写成 ###正文 时，大纲与预览仍会尽量识别；建议养成空格习惯。

预览支持列表、任务列表、引用、代码高亮、表格、链接、图片、公式、Mermaid、[TOC]、脚注；文首 YAML front matter 不显示为正文。

与 DeskTidy 联动

DeskNote 是独立进程，随 DeskTidy 一并安装，并共用设置与笔记目录。

操作说明
安装安装 DeskTidy 时会同时安装 DeskNote，无需单独勾选组件。
启用在 DeskTidy → 扩展功能 → DeskNote 中开关快捷方式（不卸载程序）。
资源管理器 · 打开方式文本 / Markdown / 代码类文件的「打开方式」列表中提供 DeskNote（不再出现 DeskTidy）。
围栏「用记事本打开」可用 DeskNote 打开文本类文件。
单实例再点一次 DeskNote 会激活已有窗口，而不是再开一份。
主题跟随 DeskTidy 当前主题设置。
