# 宠物帧：AI 生成 + 脚本处理流程

## 为什么 AI 生成的图还需要处理？

宠物引擎要求：**透明背景 PNG（RGBA）+ 统一画布尺寸 + 脚底对齐**。

而文生图 AI（豆包 / 即梦）**只能输出纯白背景 RGB**，无法直接输出真透明底
（豆包已明确说明：图像模型无法直接输出真透明 Alpha 通道）。

所以唯一必须的步骤是 **抠图**（白底 → 透明），这一步只能本地做。
其它（缩放、统一画布）是引擎尺寸要求，脚本自动完成。

## AI 要做什么（生成要求，尽量对齐最终规格）

让 AI 按下面的规格生成，能最大限度减少后处理误差：

1. **纯白背景 #FFFFFF**（豆包能做到；真透明它做不到）
2. **正方形画布**（如 2048×2048）
3. **全身入镜，水平居中**（中心偏差 ≤3px）
4. **脚底对齐底部**（距底 8~10px），角色占高约 90%
5. **同一角色所有帧构图锁定**（大小/位置/角度不变，只变动作）
6. **按命名输出**：`<角色>_<姿态>_<序号>.png`（如 `xianjian_play_0.png`）
7. **不同帧动作差异要拉开**（相邻帧不要只差一两个像素，否则动画看不清）

## 脚本要做什么（一条命令自动处理）

```
python scripts/process_pet_frames.py --src "<AI帧目录>" --char xianjian
```

脚本自动完成：
1. **rembg 抠图**（白底 → 透明）
2. 裁剪角色内容 bbox
3. 缩放到统一高度（默认 376，可 `--height` 调）
4. 统一画布（最大宽度 × 高度，脚底对齐底部、水平居中）
5. 按命名写入资产目录（源 + build 副本）
6. 自动生成 base 头像帧 `<角色>_idle.png`

处理完重启程序即可生效。

## 各姿态的帧设计

见 `pet_spec_<姿态>.md`（一个动作一个文件），含逐帧动作表。

## 一句话总结

- **AI 负责**：画角色、摆动作、对齐构图（白底）
- **脚本负责**：抠图 + 缩放 + 统一画布 + 命名入库（自动）
- **抠图必须本地做**，因为 AI 输出不了透明底
