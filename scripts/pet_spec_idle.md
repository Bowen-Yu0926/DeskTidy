# 宠物动作规格：待机 idle（xianjian_idle）

帧数：**8** 张　｜　播放：**循环**

剑仙静立，衣袂发丝随微风轻扬，神态平静。

## 角色（白衣剑仙，所有帧统一）

* 白发高髻（银白长发、束发髻、散落发丝）
* 白色汉服长袍（交领、宽袖、衣摆及踝）
* 深色腰带 + 棕色斜挎带（左肩斜跨右腰）
* 腰间酒葫芦（棕黄葫芦、黑字「酒」、红流苏）
* 右手持剑（剑尖向下）+ 背剑（左侧斜背）
* 深色长裤 + 深色靴子
* 表情：清冷、平静、淡雅

## 图片规格（每帧统一）

* 尺寸：300 × 376 像素（宽:高 ≈ 1:1.25）
* 格式：PNG，背景纯白 #FFFFFF
* 对齐：全身入镜，脚底对齐底部（0\~8px），水平居中，占高度 90%

## 帧间场景统一（核心）

1. 所有帧角色大小/位置/构图完全一致，只能动作变。
2. 主体位置稳定，只动局部（神态/发丝/衣袂/脚步）。
3. 循环动画首尾无缝（第1帧≈最后帧）。
4. 建议：以同一张站立图为底，「图生图+锁定构图/连续帧」只改动作。

## 动作设计

| 帧 | 命名 | 动作 |
| --- | --- | --- |
| 0 | xianjian\_idle\_0.png | 平静站立 |
| 1 | xianjian\_idle\_1.png | 衣袂/发丝开始轻扬 |
| 2 | xianjian\_idle\_2.png | 衣袂扬起（微风拂过） |
| 3 | xianjian\_idle\_3.png | 发丝衣袂轻扬（飘逸） |
| 4 | xianjian\_idle\_4.png | 衣袂回落 |
| 5 | xianjian\_idle\_5.png | 发丝渐静 |
| 6 | xianjian\_idle\_6.png | 恢复平静 |
| 7 | xianjian\_idle\_7.png | 回到站立（≈帧0，循环） |
