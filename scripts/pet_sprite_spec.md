# 宠物精灵图片生成规格（白衣剑仙 xianjian）— 总规格

> 给 AI 绘图工具批量生成白衣剑仙宠物动画帧的完整规格。
> **关键：请 AI 直接输出「透明背景 PNG」，这样我这边不用再抠图，直接引用。**

## 一、AI 输出要求（最重要，避免我重复处理）

1. **格式：透明背景 PNG（RGBA）**——角色不透明（alpha=255），背景**完全透明**（alpha=0）。
2. **角色抠干净**：边缘不要残留背景色/白边/光晕，发丝衣袂边缘干净。
3. **统一画布尺寸**：同一角色所有帧的**画布宽高完全一致**（见下方「对齐」）。
4. **角色对齐**：
    * 全身入镜，不裁切
    * **脚底对齐画布底部**（留 0\~8px）
    * **水平居中**
    * 角色头顶到脚底约占画布高度 90%
5. **统一高度**：角色高度统一（所有帧、所有姿态），宽度按角色比例自然变化。
6. **不跑形**：同一角色所有帧，配色/体型/五官/道具位置完全一致，只变动作。

> 如果 AI 无法输出透明背景，可退而给**纯白背景 #FFFFFF**，我这边会自动抠图（rembg），但透明 PNG 最省事、最保真。

## 二、我这边怎么处理（规则，供你了解）

如果你给的是透明 PNG，我直接引用（缩放 + 命名 + 接入）。
如果给的是白底，我会：

1. rembg 抠图（AI 抠图，去背景）
2. 裁剪角色内容 bbox
3. 统一高度缩放
4. 放到统一画布（脚底对齐 + 水平居中）
5. 按命名规则重命名 + 接入宠物

## 三、角色（所有帧统一）

* 白发高髻（银白长发、束发髻、散落发丝）
* 白色汉服长袍（交领、宽袖、衣摆及踝）
* 深色腰带 + 棕色斜挎带（左肩斜跨右腰）
* 腰间酒葫芦（棕黄葫芦、黑字「酒」、红流苏）
* 右手持剑（剑尖向下）+ 背剑（左侧斜背）
* 深色长裤 + 深色靴子
* 表情：清冷、平静、淡雅

## 四、流畅性核心要求

1. 连续帧 = 同一动作的均匀分解，相邻帧只差一小步。
2. 循环动画（idle/walk/sleep/wait/play/hold）**首尾无缝**（第1帧≈最后帧）。
3. 主体位置稳定，只动局部（神态/发丝/衣袂/脚步）。
4. 动作符合剑仙人设：**从容、飘逸、帅气**，幅度小，不蹦跳、不夸张、不四仰八叉。
