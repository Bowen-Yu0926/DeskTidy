# QA-DT-PUB-DRAG-001 公共浮层多选 / 批量拖拽（Fences 对齐）

## 目的
整理模式下（Explorer 图标隐藏），浮动图标框选后可批量拖到分区或文件夹，取消拖拽不丢图标、不闪到左上角。

## 前置
- DeskTidy Native 已启动，桌面图标隐藏，当前页有 ≥3 个未钉选浮动文件
- 至少有一个可见分区

## 步骤与期望

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 在空白处拖出橡皮筋框住 ≥2 个浮动图标 | 蓝框出现；图标宿主不位移；松手后选中高亮保留 |
| 2 | 点空白取消选中 | 无闪屏；图标留在原位 |
| 3 | 再框选 ≥2 个图标，按住其中一个拖出宿主到「文档」等分区松手 | 文件进入分区；浮动层不再显示这些项；无整页闪一下后「消失」 |
| 4 | 框选 ≥2 个，拖到资源管理器某文件夹（移动） | 桌面浮动项移除；文件在目标文件夹 |
| 5 | 框选 ≥2 个，拖起后按 Esc / 拖回空白松手取消 | 图标仍在原浮动位置，不叠到鼠标一点 |
| 6 | 单选一个浮动图标，在宿主内拖到另一空槽 | 仅重排位置，不误触发 OLE 丢文件 |
| 7 | 单选拖到分区 | 钉入分区，浮动层移除该项 |

## 对标
Fences / Explorer：多选后阈值内即 shell 拖拽；图标容器几何在框选/拖拽过程中不变；取消拖拽不重写整批坐标。松手落在桌面/公共浮层 → **取消 OLE**（文件已在 Desktop，禁止同目录 CF_HDROP）；松手落在分区 → 虚拟钉选；松手落在资源管理器文件夹 → MOVE/COPY。

## 本机冒烟素材
桌面可放 `DeskTidyDragTest_1/2/3.txt` 做框选批量拖入分区 / 取消拖 / 拖进文件夹。
